## Memory quality (ADR 0015)

No new tool; `tools/list` must not grow (new `kb_write` fields paid by trims in the same change).
- [x] Phase 1, store (`acta-core`, integration-engineer): schema 7 (`verified_at`/`verified_by` backfilled, `state`, `superseded_by`, context and provenance columns, `kb_revisions.session`/`branch`, `kb_links`, `kb_pairs`, local `kb_quality_log`, `kb_verified` index); `kb_verify`, `kb_supersede` (one transaction with the successor's write), `kb_retire`, `kb_make_live`, `kb_merge` (survivor revision, links copied, wider level, pair resolved); verified date set only by content writes; the Overview count on `verified_at` and live state; export format + 1 with the old-version import test. Tests: backfill, every state change and its undo, superseded and retired left out of `kb_scope` and search but readable by id, merge at the wider level, round trip. Done on `integration-engineer/memory-quality` (`store/kb.rs`, `store/kb_quality.rs`, schema V7, export format 5): `kb_create_with`/`kb_update_with` take a `KbWriteCtx` (session, focus topic, branch, context folder and branch, sources); `kb_supersede` takes the successor's write (`KbSuccessor::Create` or `Update`) and supersedes one to three live entries of the same project in its transaction; verify, retire (reason as the revision's `section`, 200 chars), make live and merge each write a revision with the text unchanged (new change kinds `verified`, `superseded`, `retired`, `made_live`, `merged`); `kb_merge` returns a `KbMergeTrace` and `kb_unmerge` takes it back in one step (refused once the survivor changed); merge lives at the narrowest owner holding both (two topics of one epic: the epic). Sources (`kb_add_links`, `kb_links`: records by UUID, commits, repository-relative paths with folder and blob); pairs (`kb_record_pair` keeps a `distinct` decision, `kb_set_pair_state`, `kb_pairs_of`); the local log (`kb_log`, `kb_log_since`, pruned at 180 days, never exported). - [x] Phase 2, checker (`acta-core::kb_quality`, pure functions): normalisation (NFKD, en and fr stop words and suffixes), trigram and token Jaccard, the conflict signals (polarity, antonyms, values), FTS prefilter over owner, ancestors and descendants; `kb_flags` for the store flags.
